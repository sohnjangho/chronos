# 접속 기록 탭 설계 (2026-11-25)

## 왜
PM 이 심사 서버에서 **심사위원이 어떤 기능을 쓰고 에이전트에게 무엇을 물었는지** 나중에 보려 한다.
지금은 질문(개발 콘솔 「실행 추적」, 최근 200턴·앞 60자, 계정 구분 없음)만 남고, 기능 사용·로그인 이력은 남지 않는다.

## 목표 / 비목표 / 실패 조건
- 목표: 개발 콘솔에 「접속 기록」 탭 하나. 계정을 고르면 ① 에이전트 대화(대화 세션별) ② 만든 프로젝트 ③ 쓴 기능(시간순)이 보인다.
- 비목표: 접속 주소(IP)·User-Agent 원문 저장(기존 방침 유지 — 기기는 기존 기기 줄의 브라우저·OS 낱말로만), 기록 지우기·내보내기, 실시간 알림.
- 실패 조건: 기록 때문에 요청이 느려지거나 실패함 · 접속 신호처럼 저절로 도는 요청이 목록을 덮음 · 관리자가 아닌 사람이 기록을 봄.

## 방법 (PM 선택: A)
- **A. 서버가 요청마다 기록 (선택)** — 화면 수정 없이 실제 동작이 다 남는다. 길 → 기능 이름 표가 필요하다.
- B. 화면이 창 열기 신호 — 읽기 쉽지만 창 안 동작이 빠지고 화면 여러 곳 수정.
- C. 새로 안 만듦 — 기능 사용을 못 본다.

## 설계
**저장** — 새 표 `activity_log`(줄 지우지 않음): `id, user_id(없으면 null), at(UTC), method, route(길 틀, 예 /api/schedules/{schedule_id}/delays), feature(한국어 기능 이름), schedule_id(null 가능), device_id(null 가능), status(HTTP 코드)`.

**기록 지점** — 미들웨어가 응답 뒤에 한 줄 쓴다. 실패해도 응답에는 영향 없음(삼키고 로그만).
- 쓰는 것: 로그인한 사람의 `/api/*` 요청 중 무시 목록 밖. 로그인 성공·실패(실패는 입력한 아이디로 계정을 찾아 user_id, 없으면 null + 아이디 앞 20자).
- 빼는 것: 접속 신호(`/api/me/presence`), 화면 상태 저장(`/api/me/ui-state`), 상태·건강 확인, 정적 파일, 개발 콘솔 자신의 읽기(GET `/api/devconsole/*`).
- 같은 사람·같은 기능의 GET 이 1분 안에 되풀이되면 새 줄 대신 건너뛴다(목록 폴링 억제).

**기능 이름** — 길 틀 앞부분 → 이름 표(`app/store/activity_names.py`). 예: `POST /api/chat/sessions/{id}/messages` → 에이전트 질문, `/delays` → 지연 분석, `/scenarios` → 만회 시나리오, `/approvals` → 승인, `/reports` → 보고서, `/points` → 관리 포인트, `/field` → 현장 진도, `/outreach` → 연락, `/contacts` → 연락처, `/files` → 파일, 설정 길 → LLM·알림·외부 API 설정. 표에 없으면 길 틀을 그대로 보인다.

**만든 프로젝트** — 일정의 버전 1 작성자 이름(`by_name`)이 그 계정 이름인 것(에이전트 `create_project`·승인 적용 모두 사용자 이름을 쓴다). 씨앗(시연 일정)은 작성자가 달라 빠진다.

**에이전트 대화** — 그 계정의 대화 세션(제목·만든 시각·다룬 일정)별로 사용자 글과 에이전트 답(도구 메시지 제외)을 시간순. 각 질문 줄에 「실행 추적」 상세로 가는 링크. 관리자 전용 탭에서만 다른 사람 대화를 본다(기존 "만든 사용자만 본다" 규칙의 관리자 예외).

**API**(관리자 전용, `/api/devconsole/activity`)
- `GET /accounts` → 계정별 이름·아이디·역할·마지막 접속·로그인 수·로그인 실패 수·대화 수·기능 사용 수.
- `GET /accounts/{user_id}` → `{chats:[{id,title,created_at,schedule,messages:[{role,text,at,turn_id}]}], projects:[{id,name,domain,created_at}], features:[{at,feature,method,route,schedule,device,status}], summary:[{feature,count}]}`. 기능 줄은 최근 500개.

**화면** — 개발 콘솔 탭 「접속 기록」(「업데이트 내역」 앞).
```
┌ 계정 ───────────────┐┌ 심사위원 (judge · 관리자) 마지막 접속 11-26 10:12 ───────┐
│ 심사위원  10:12  ●  ││ [대화 3] [프로젝트 1] [기능 사용 42]                     │
│ 관리자    어제      ││ ─ 대화 ──────────────────────────────────────────────    │
│ (로그인 실패 2)     ││ ▸ 「R&D 일정 지연 분석해줘」 11-26 10:01 · 일정: 수소…    │
└─────────────────────┘│   사용자 10:01  성능 시험이 3일 늦어지면…  [실행 추적 →] │
                       │   에이전트 10:02 크리티컬 경로가 …                       │
                       │ ─ 기능 사용 (많이 쓴 순 요약 칩 + 시간순 목록) ─────────  │
                       │ 10:12 보고서 만들기 · 수소… · Chrome/macOS              │
                       └──────────────────────────────────────────────────────────┘
```
세 묶음은 탭 안 하위 탭(대화 · 프로젝트 · 기능 사용). 긴 목록은 기능별 거르기 + 찾기(화면 검수 4항목).

## 제약
- 심사 서버 재배포(새 휠)로 적용. 제출 마감(11-25 23:59) 뒤에 들어간다 — 저장소 제출본과 심사 서버 코드가 달라진다.
- 심사위원 계정이 관리자라 심사위원도 이 탭을 볼 수 있다(자기 기록·PM 기록). 한 계정을 여러 심사위원이 함께 쓰면 사람은 구분 못 하고 기기(브라우저·OS)로만 갈린다.
- 시험: 미들웨어(기록·무시·1분 억제·실패 무해), 이름 표, 두 API, 탭 화면.
