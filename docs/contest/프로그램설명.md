# 프로그램 설명 (기획서 새 장 · 원고)

> 넣는 곳: 3장(시연) 뒤, 4장(확장) 앞. 「ChronOS 의 앱 19개」.
> 쪽 구성: 앱마다 큰 화면 1장 + 기능 2~3줄. 한 쪽에 앱 2~3개. 화면은 개발 세션 캡처 `chronos-film/recordings/apps/` 에서.
> 각 앱의 「에이전트가 쓰는 방식」 줄은 OS 와우 지점(에이전트가 창을 직접 연다)과 이어지게 썼다.

## 시스템 앱

### 01 에이전트 대화
말 한 줄로 일을 시키는 곳. 결과는 글이 아니라 카드로 돌아온다.
- 결과 카드: 일정 생성, 질문지, 지연 영향, 관리 포인트, 당김 효과, 만회안, 근거, 차트, 문자·전화 초안
- 대화 정보: 지금 다루는 일정, 보는 화면, 가정, 워크플로우 단계, 사용량
- 대화마다 모델 고르기, 파일 붙이기(10개, 50MB), 답 중단
- 에이전트가 쓰는 방식: 모든 일의 출발점. 여기서 받은 요청으로 다른 창을 연다.

### 02 질문지
일정을 만들기 전에 모자란 정보를 묻는 창.
- 질문마다 「왜 묻나요」와 추천 선택지, 직접 입력
- 답하지 않은 질문은 적어 둔 가정으로 넘어간다
- 대화와 자료에서 미리 채운 칸은 따로 표시
- 에이전트가 쓰는 방식: 질문이 셋 이상이면 에이전트가 이 창을 띄운다.

### 03 워크플로우
에이전트가 짠 단계를 그래프로 보여 주고, 잘 된 순서를 스킬로 저장한다.
- 단계 그래프가 실시간으로 자란다
- 단계 상세: 도구, 까닭, 모델, 받은 것과 돌려준 것, 시간, 비용
- [스킬로 저장] → 다음 비슷한 요청에 다시 쓴다
- 에이전트가 쓰는 방식: 「워크플로우 창만」 모드에서는 이 창 하나로 진행을 보여 준다.

### 04 승인함
일정을 바꾸는 결정은 여기서 사람이 한다.
- 대기 건 상세: 승인이 필요한 이유, 바뀌는 작업 표, 조건 점검, 기한 여유
- [승인하고 반영] [거부] [거부하고 다시 짜게 하기]
- 자동 적용된 건은 [되돌리기]
- 에이전트가 쓰는 방식: 에이전트는 올리기만 하고 승인하지 못한다. 현장 관리자도 승인하지 못한다.

### 05 탐색기
일정 파일과 버전을 보관하는 곳.
- 분야별 일정 목록
- 버전 목록과 [되돌리기] (옛 버전은 모두 남는다)
- 에이전트가 쓰는 방식: 일정 목록과 버전을 읽는다.

### 06 설정
개인 화면 설정과 관리자용 연결·정책.
- LLM 연결(Liner)과 작업별 모델 배정(cost · balanced · quality)
- 알림 연결: 문자·AI 전화, 시험 모드, 발송 권한(승인 받기 / 위임), 음성 진단
- 화면: 에이전트 작업 연출(스테이지 창 전환 · 워크플로우 창만 · 끄기), 기기 형태
- 분야별 바깥 자료 켜고 끄기, 정보 API 연결, 계정과 가입 승인, 승인 수준

### 07 개발 콘솔 (관리자)
에이전트의 속을 들여다보는 곳.
- 에이전트 구조도와 이번 요청의 실행 흐름도
- 하네스 차단 시험, 연락 하네스 상황 × 채널 격자
- 실행 추적(관리 포인트·연락 단계 포함), 시스템 진단, 사용량과 비용

## 일정 앱

### 08 스케줄
작업을 표로 보고 직접 고친다. 날짜는 모두 코드가 계산한 값이다.
- 칸 편집, WBS 묶음 접기, 행 추가·삭제
- 관계 패널: 선행·후행(FS/SS/FF/SF + 간격)
- Plan 보다 늦어지면 「지연 기록 열기」 알림, 협력사 연락
- 에이전트가 쓰는 방식: 요청 속 작업을 여기서 찾아 보여 준다.

### 09 간트차트
막대로 계획과 실적을 겹쳐 본다.
- 층: Plan / 실적·예측 / 크리티컬(빨강), 마일스톤, Data Date, 작업 금지 띠
- 묶는 기준: WBS / 자원(생산 일정은 설비별)
- 막대를 끌어 고치고, 조건 미리 보기는 점선으로

### 10 CPM
작업을 카드로, 관계를 화살표로 그린 네트워크도.
- 크리티컬 경로만 보기, 상세 패널(ES/EF, LS/LF, 여유)
- 위 요약: Plan 준수율, 크리티컬 변동, 완료 편차, 만회 계획 달성률
- 화살표를 눌러 관계 고치기

### 11 공정률 (+ 현장 점검)
계획 대비 실적 대시보드와 현장 협업 허브.
- S-커브, SPI 추이, 마일스톤, 지연 상위, 앞으로 3주, 위젯 배치 편집
- 현장 점검 4탭: 일일 체크인, 사진 AI 판독, 만회안 의견 조회, D-3 핸드오프
- 못 읽은 사진은 「사람 판독 대기」로 관리자에게

### 12 관리 포인트
지금 준공일을 좌우하는 작업을 주별로 본다.
- 이번 주 · 다음 주 · 그다음 주 보드, 작업마다 여유와 담당 협력사
- 버전마다 무엇이 들어오고 빠졌는지 「바뀜 기록」
- 카드에서 바깥 위험, 당김 효과, 담당자 연락으로 이어짐

### 13 비교판
여러 안을 같은 척도로 견준다.
- 같은 차트 / 좌우 비교 / 차이 표
- 요약 표: 준공, Plan 대비, 기한 여유, 크리티컬 수, 조건 위반, 준공 반영, 다음 결정 줄
- 「만약에」 복사본 만들기, [이 안을 반영(승인함으로)]

### 14 조건·규칙
일정에 걸린 조건을 4겹으로 보고, 바꿔 미리 본다.
- 4겹: 기본 규칙 · 분야 규칙 · 내 규칙 · 입력 조건
- 값을 바꾸면 「준공 A → B · 위반 n」 미리 보기, 간트에 점선
- 내 규칙: 에이전트가 제안하고 사람이 승인해 쌓인다

### 15 지연 기록
늦어진 사건을 기록하고 영향을 본다.
- 준공 영향 누적, 책임별 영향, 여유로 흡수된 지연, 비용 환산
- 사건 상세의 영향 분석: 준공 변화, 크리티컬 변화, 새 자원 겹침
- [간트에서 보기] [비교판에서 보기] [만회 계획 요청]

### 16 보고서
월간·분기 보고서를 회사 양식대로 쓴다.
- 지난 보고서 파일을 올리면 구조와 문체를 배워 양식으로 기억
- 블록마다 AI 에게 고쳐 달라 하고 「다음에도 기억」
- 표 숫자는 코드 값, 차트 숫자는 전수 대조, PDF·Word 로 내보내기

## 연결 앱

### 17 프로젝트 관리
AI 가 통화·문자에서 쓰는 현장 기본 정보.
- 프로젝트 이름, AI 가 부를 이름(예: 「성수동 사무동 신축현장」), 주소, 한 줄 소개, 발주처

### 18 연락처
협력사 주소록과 문자·AI 전화.
- 프로젝트별 주소록: 근무시간, 성별, 언어, 가린 번호
- 문자 대화: 에이전트 초안 → 사람이 [보내기], 예약, 번역
- 통화: 전화 걸기 창(물어볼 것 · 말하지 않을 것), 통화 카드(질문별 답과 근거), 받아쓰기, 걸려 온 전화 받기
- 확인할 연락처, 확인할 보고, 모르는 번호

### 19 자료함
대화로 올린 문서·사진·공정표를 AI 가 분류해 둔 창고.
- 5축 분류: 종류 · 공종 · 현장 · 시기 · 출처
- 뜻과 낱말로 찾기, 미리 보기, [대화에 붙이기]
