# 알림톡 문안 초안 (나중에 검수 신청할 것)

> 2026-11-24 · 계획 4 Task 101. **[PM 11-23] 카카오톡은 연결만 만들고 지금은 쓰지 않는다.** 이 문서는 채널이 생긴 뒤 카카오 검수에
> 낼 문안의 초안이다. 아직 아무것도 등록·신청하지 않았다.

## 준비 차례

1. **카카오톡 비즈니스 채널을 만든다.** 알림톡용 채널은 카카오 정책상 **사업자 인증이 필요할 수 있다**(한국AI통신 문서에는
   요건이 적혀 있지 않음). **지금은 만들지 않는다** — 만들 수 있는지 PM 이 먼저 확인한다.
2. **한국AI통신 콘솔에서 채널을 연결한다**(채널 검색용 ID + 채널 관리자 휴대전화로 온 인증번호).
3. **알림톡 문안을 등록하고 카카오 검수를 받는다.** 승인 전에는 보낼 수 없다. 아래 초안을 고쳐서 낸다.
4. **설정 → 알림 연결 → 카카오톡에서 [상태 읽기]를 누르고, 승인된 문안을 쓰는 곳(아래 「쓰는 곳」 이름)에 잇는다.** 문안마다
   「카카오톡이 안 될 때 보낼 문자」도 같이 넣는다.

이 차례를 다 마쳐도 앱이 바로 알림톡을 보내지는 않는다. 알림톡을 실제로 보내는 길(카카오톡 통로)은 채널이 생긴 뒤 따로
만든다. 그 전까지는 카카오톡을 고르면 **문자로** 나간다.

## 문안을 쓸 때 지킨 것

- **정보성 알림만** 쓴다(광고·할인·홍보 글 없음). 받는 사람에게 이미 맡겨진 일에 대한 알림이다.
- 바뀌는 곳은 모두 `#{이름}` 꼴의 변수로 둔다. 변수 밖의 글은 검수받은 그대로만 나간다.
- **카카오톡으로는 답을 받을 수 없다**(알림톡은 보내기만). 그래서 모든 문안 끝에 문자로 답하라는 한 줄을 둔다:
  **「답은 이 번호로 문자 주세요: 070-0000-0000」**(가상 번호 — 등록할 때 우리 발신번호로 바꾼다). 앱은 문안에 「문자」와
  「이 번호」(또는 우리 발신번호 끝 4자리)가 있는지 보고 설정 화면에 「답 받는 줄 있음」을 표시한다.
- 문안마다 같은 뜻의 **문자 대신 보내기 글**을 둔다(카카오톡을 쓰지 않는 사람, 알림톡 실패, 채널이 준비되지 않았을 때).
  문자 글은 90자 안팎으로 짧게 하고, 같은 변수를 쓴다.
- 사람·회사·현장 이름은 아래 예시처럼 모두 가상이다.

## 문안 초안

### 1. 체크인 요청 (쓰는 곳: `체크인 요청`)

변수: `#{이름}` `#{현장}` `#{날짜}` `#{작업}`

```
[크로노스 공정 알림]
#{이름}님, #{현장} #{날짜} 작업 체크인을 부탁드립니다.

- 작업: #{작업}
- 확인할 것: 오늘 투입 인원, 시작 시각, 막히는 점

답은 이 번호로 문자 주세요: 070-0000-0000
```

문자 대신 보내기:

```
[크로노스] #{이름}님, #{현장} #{날짜} #{작업} 체크인 부탁드립니다(인원·시작 시각·막히는 점). 이 번호로 답 문자 주세요.
```

예시: 박현장님, 가람현장 11월 30일 작업 체크인을 부탁드립니다. 작업: 3층 슬래브 타설.

### 2. 일정 변경 알림 (쓰는 곳: `일정 변경 알림`)

변수: `#{이름}` `#{작업}` `#{이전날짜}` `#{새날짜}` `#{까닭}`

```
[크로노스 공정 알림]
#{이름}님, 맡으신 작업의 일정이 바뀌었습니다.

- 작업: #{작업}
- 바뀌기 전: #{이전날짜}
- 바뀐 뒤: #{새날짜}
- 까닭: #{까닭}

어려운 점이 있으면 답은 이 번호로 문자 주세요: 070-0000-0000
```

문자 대신 보내기:

```
[크로노스] #{이름}님, #{작업} 일정이 #{이전날짜}에서 #{새날짜}로 바뀌었습니다(#{까닭}). 어려우면 이 번호로 답 문자 주세요.
```

### 3. D-3 준비 확인(핸드오프) (쓰는 곳: `D-3 준비 확인`)

변수: `#{이름}` `#{작업}` `#{시작일}` `#{앞작업}`

```
[크로노스 공정 알림]
#{이름}님, #{작업} 시작이 3일 남았습니다(#{시작일}).
앞 작업(#{앞작업})이 끝나는 대로 넘겨받으실 수 있도록 준비 상태를 알려 주세요.

- 자재: 준비됨 / 아직
- 장비: 준비됨 / 아직
- 인력: 준비됨 / 아직

답은 이 번호로 문자 주세요: 070-0000-0000
```

문자 대신 보내기:

```
[크로노스] #{이름}님, #{작업} 시작 3일 전입니다(#{시작일}). 자재·장비·인력 준비 상태를 이 번호로 답 문자 주세요.
```

### 4. 승인 대기 알림 (쓰는 곳: `승인 대기 알림`)

변수: `#{이름}` `#{건명}` `#{올린날짜}`

```
[크로노스 공정 알림]

- 건: #{건명}
- 올린 날: #{올린날짜}

승인·반려는 크로노스 앱의 승인함에서 해 주세요.
문의는 이 번호로 문자 주세요: 070-0000-0000
```

문자 대신 보내기:

```
[크로노스] #{이름}님, 승인을 기다리는 건이 있습니다: #{건명}(#{올린날짜}). 승인함에서 확인해 주세요. 문의는 이 번호로 문자 주세요.
```

### 5. 회신 전화 예약 알림 (쓰는 곳: `회신 전화 예약`)


### 6. 수신 거부 확인 (쓰는 곳: `수신 거부 확인`)

변수: `#{이름}`

```
[크로노스 공정 알림]
#{이름}님, 앞으로 크로노스 공정 알림(문자·카카오톡·전화)을 보내지 않겠습니다.

다시 받으시려면 이 번호로 문자 주세요: 070-0000-0000
```

문자 대신 보내기:

```
[크로노스] #{이름}님, 앞으로 공정 알림을 보내지 않겠습니다. 다시 받으시려면 이 번호로 문자 주세요.
```

## 검수 신청 전에 PM 이 정할 것

- 문안 머리말 `[크로노스 공정 알림]` 과 채널 이름.
- 「답은 이 번호로 문자 주세요」의 번호(우리 발신번호 — 070 번호가 문자를 받을 수 있는지 먼저 확인).
- 승인 대기 알림에 앱 주소를 넣을지(넣으면 버튼형 문안으로 따로 검수받는다).
