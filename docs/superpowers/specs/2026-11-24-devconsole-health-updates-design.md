## 시스템 진단(A)
- 상태 말은 넷: 정상·확인 필요·실패·모름(지금 9가지를 대응표로 모음).
- 맨 위 한 줄 판정(「모두 정상」/「n개가 멈췄습니다」/「확인할 것 n개」) + 개수 칩(누르면 거름) + 찾기 + 접속·기기·실행 중 턴 수 + 「다시 점검」.
- 「먼저 볼 것」: 실패 → 확인 필요 → 모름 순, 한 줄씩 + 할 일, 누르면 펼침(지금 상태·영향·기계 출력 접힘).
- 나머지는 영역 4묶음 2열: AI·검색 / 자료 / 문자·카카오톡·전화 / 지금 접속·실행 중. 한 항목 한 줄, 쉬운 이름 + 작은 기술 이름, 마지막 확인 시각(서버가 안 주면 진단을 부른 시각 — PM 동의).
- 서버 응답은 그대로, 화면 쪽 대응표만. 실행 중 턴 「강제 중단」은 지금 기능 그대로.

## 업데이트 내역(U1)
- 개발 콘솔 새 탭 「업데이트 내역」. 판마다 카드(시각·제목·짧은 커밋·「지금 실서버 판」 표시·주의 한 줄·새 기능/고침/안전 세 칸), 새것이 위, 날짜 묶음, 갈래 칩·찾기.
- 기록 파일 `deploy/updates.jsonl`(한 줄 = 한 판). 컨트롤러가 재시작할 때마다 한 줄 붙임.
- 「지금 실서버 판」 = 서버가 켤 때 읽은 자기 커밋(작업 폴더의 git HEAD, 없으면 표시 없음).
- 관리자만(개발 콘솔과 같음).
