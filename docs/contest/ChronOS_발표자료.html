01 · 문제 정의 — 공종별 검토 지옥과 기존 도구의 한계

혼자 고쳐도 끝이 아니다 — 공종별 전문가 검토

👷 공종별 검토·취합 병목

골조·토목·전기·설비 담당자마다 시방서·도면·일정을 돌려 확인하고 합의하는 데만 며칠이 소요됩니다.

📊 전문 도구 vs 엑셀의 딜레마

전문 도구(P6)는 무겁고 AI와 단절돼 있고, 엑셀은 CPM·자원 맞춤 계산을 못 해 사람이 손으로 풉니다.

🤖 범용 AI 챗봇의 치명적 한계

공정표를 챗봇에 넣으면 날짜와 크리티컬 패스가 환각으로 깨지고, 맞는지 검증할 방법이 없습니다.

02 · 솔루션 — ChronOS 3대 원칙

계산은 코드, 판단은 Liner, 결정은 사람

① 결정론적 코드 엔진 (환각 0%)

LLM은 WBS·기간·선후 관계만 냅니다. 날짜·여유(Float)·자원 맞춤·지연 영향은 코드가 계산하며 LLM 날짜는 버립니다.

② 4겹 하네스 & 정직한 검증

기본 → 분야 → 내 규칙 → 입력 조건을 4겹으로 자동 점검합니다. 코드로 못 재는 조건은 「자동 점검 안 됨」으로 솔직히 밝힙니다.

③ 승인함 & 버전 되돌리기

준공·마일스톤·크리티컬·조건이 바뀌면 승인함으로 이동합니다. 거부 시 사유를 반영해 AI가 다시 짜며 모든 변경은 되돌립니다.

03 · 완성도 — 고통 ① 해결: 수십 가지 조건 검토

조건 하나 바꾸면 1초 만에 점선 미리 보기

타워크레인 1대 → 2대 변경 시

준공 예정일 2027.10.29 → 2027.09.24 (-35일) · 위반 0건 · 자동 점검 안 됨 5건 정직 표시

03 · 완성도 — 고통 ② 해결: 밤샘 만회 계획

"골조가 3일 밀렸어" → 만회안 비교판 즉시 생성

1. 지연 영향 자동 계산

여유 흡수 0일 · 준공 +3일(11.02) · 타워크레인 겹침 감지 — Plan은 옮기지 않고 늦음으로 표시

2. 코드 탐색 + Liner 추천

병행·압축·자원 추가를 코드가 한 수씩 시뮬레이션 → 만회안 B(10.01, 목표 도달, 위반 0) 추천

3. 같은 차트 · 다중 안 요약표

현재·Plan·지연 반영안·만회안 A/B를 한 화면에서 비교하고 바로 승인함으로 제출

03 · 완성도 — 고통 ③ 해결: 공종별 검토 · 자료 · 승인

시방서·사진·날씨·법규·승인까지 한 곳에서 끝낸다

📁 5축 자동 자료함 + Qdrant 뜻 검색

PDF·현장 사진·엑셀 공정표를 대화에 붙이면 종류·공종·현장·시기·출처 5축으로 자동 분류·검색

🌦️ 기상청 API + Liner 법령·기업 근거

동절기/우천 일수(기상청 ASOS·예보)와 인허가·납기(Liner MCP)를 조건 출처 링크로 자동 첨부

✅ 공종/PM 승인함 & 거부 시 재작성

사유·영향 요약과 함께 승인 대기 → 거부 사유를 적으면 에이전트가 반영해 다시 짭니다
