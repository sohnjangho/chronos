## 1. 먼저 확인할 것 (녹화 전, 30분 안)

1. **AI 공정표 초안을 R&D 실증 과제로 만들 수 있는가?**
   - 「100kW급 수소 연료전지 발전 실증 과제 공정표 만들어줘」라고 했을 때, 초안에 인허가 작업이 **실제로** 들어가야 한다.
     - 실증특례(규제 샌드박스) 신청·심의

     - 완성검사·사용전 검사
   - 처리 기간의 근거가 Liner 검색(법령·업계 소식)으로 붙는지도 확인한다.

2. 아래 2절의 시연 일정을 넣었을 때 CPM 숫자(여유, 크리티컬 패스 이동)가 3절의 장면 흐름대로 나오는가?
3. 외부 영향 검색(Liner Search / Premium Data / MCP)이 아래 관리 포인트에 대해 6개월 안의 출처를 돌려주는가?

## 2. 시연 일정 (가상): 「가상 · 100kW급 수소 연료전지 발전 실증 과제」
- 수행기관(가상): 크로노 에너지 연구소. 공동연구(가상): 한빛대 연료전지 시험센터. 실증 부지(가상): ○○시 산업단지.
- 과제 기간: 2026-04-01 ~ 2028-06-30. 데이터 기준일은 2027년 초가 알맞다(연구 막바지, 실증 직전).
- 끝 작업은 「과제 종료(결과 보고)」이다. 화면에서는 「완료일정」 = 과제 종료일이다.

두 갈래가 만나는 구조로 짠다. 숫자는 예시다. CPM이 3절 흐름을 내도록 개발 세션이 조정한다.

| 갈래 | 작업 (예시 기간) |
|---|---|
| A 연구 | 스택 설계 → 시제품 제작 → **성능 시험** → 내구 시험 → 실증 설비 설계 확정 → 실증 설비 제작 → 설치 |
| B 인허가 | **실증특례 신청 → 특례 심의(약 90~120일)** → 고압가스 시설 설치 허가 → (A의 설치와 합류) |
| 합류 뒤 | 설치 공사 → 완성검사·사용전 검사(가스안전공사) → 시운전 → **실증 운전 12개월** → 결과 보고 = 과제 종료 |
| 곁가지 | 측정 장비 구매, 데이터 수집 시스템 구축, 협력사 부품(막전극접합체·BOP) 조달 — 여유가 큰 작업 |

장면별로 필요한 숫자:
- 시작 시점에는 완료일정을 좌우하는 일이 **B 인허가 갈래**(특례 심의 → 설치 허가)여야 한다. 일정을 짤 때 인허가를 넣었기 때문에 처음부터 보인다는 메시지다.
- 「같은 3일」:
  - (가) 데이터 수집 시스템 구축이 3일 늦어진다. 여유가 크다(예: 18일). 아무것도 바뀌지 않는다.
  - (나) **성능 시험 재시험**으로 3일 늦어진다. 과제 종료일은 그대로지만, A 연구 갈래의 여유가 4일에서 1일로 줄어 관리 포인트가 바뀐다. 첫 장면 실패 사례(성능 시험 재시험)와 같은 작업이다.
