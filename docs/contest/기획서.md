# ChronOS 기획서 — .EXE-THON 2026

> **한 줄 요약**: 하루에도 수십 번 변하는 스케줄 — 밤새 고쳤더니 내일 또 바뀌는 고통과 공종별 검토 지옥을 끝내는 **에이전트 OS, ChronOS**.  
> 계산은 코드(환각 0%), 판단·조사는 Liner API 5종, 최종 결정은 사람(승인함).

---

## 1. 문제 정의 (30%) — 「밤새 고친 공정표, 아침이면 또 바뀐다」

### 1-1. 현장의 진짜 고통
건설·플랜트·생산 현장의 스케줄은 **하루에도 수십 번 바뀝니다.** 비가 오고, 자재가 늦고, 장비가 겹치고, 발주처가 마일스톤을 당깁니다.

1. **수십 가지 상황을 동시에 검토해야 한다**: 작업 하나가 밀리면 날씨·법규·장비 대수·선후행 관계·여유(Float)·크리티컬 패스·협력사 납기까지 수십 가지 조건을 한꺼번에 따져야 합니다.
2. **밤새 고쳤더니 내일 또 바뀐다**: 밤새 엑셀과 전문 도구를 뒤집어 겨우 만회 계획을 세웠더니, 다음 날 아침 현장에서 또 변경이 터집니다. *"언제까지 이 고통을 반복해야 할까?"*
3. **공종별 전문가 검토·협의가 끝이 없다**: 골조·토목·전기·설비 각 공종 담당자에게 도면·시방서·일정을 돌려 검토받고 승인받는 과정 자체가 병목입니다.

| 반복되는 현장 업무 | 기존 소요 시간 | 병목 원인 |
|---|---|---|
| 진도 지연 시 만회 계획 수립 | 반나절 ~ 밤샘 | 수십 가지 제약·크리티컬 패스 수작업 재계산 |
| 발주처 요구로 조건·마일스톤 변경 | 반나절 ~ 하루 | 자원 겹침·선후행 연쇄 영향 확인 불가 |
| 공종별 시방서·도면·회의록 대조 및 검토 | 매주 수 시간 | 문서가 흩어져 있고 변경 근거 추적이 어려움 |
| 협력사 엑셀 공정표 취합·검토 | 건당 2~3시간 | 양식 제각각, 빈 칸 확인, 수기 입력 |

### 1-2. 왜 기존 도구도, 일반 AI도 못 푸는가?
| 접근 | 한계 |
|---|---|
| **전문 공정 도구 (P6 등)** | 배우기 어렵고 무거우며, 현장 문서·대화·AI 판단과 단절됨 |
| **엑셀 공정표** | CPM·자원 맞춤 자동 계산이 없어 사람이 밤새 손으로 계산 |
| **범용 AI 챗봇 (ChatGPT 등)** | 공정표를 통째로 넣으면 **날짜와 크리티컬 패스가 환각으로 깨지고**, 검증할 방법이 없음 |

## 2. 솔루션 & 완성도 (30%) — ChronOS

### 2-1. 3대 설계 원칙
1. **계산은 코드, 판단·설명은 Liner AI**: LLM은 WBS·기간·선후 관계·판단만 냅니다. 날짜·여유(Float)·자원 겹침·조건 통과 여부는 결정론적 엔진(`app/core`·`app/harness`)이 계산합니다. LLM이 보낸 날짜는 버립니다.
2. **수십 가지 조건을 4겹 하네스로 구조화**: `기본 규칙` → `분야 규칙` → `내 규칙(베테랑 노하우)` → `현장 입력 조건`을 4겹으로 조립·검증합니다. 자동 점검 불가능한 조건은 **「자동 점검 안 됨」**으로 명시해 절대 통과로 속이지 않습니다.
3. **AI는 제안, 사람은 승인 (Human-in-the-loop)**: 준공일·마일스톤·크리티컬 패스·조건이 바뀌는 중요한 변경은 반드시 **승인함**을 거칩니다. 거부 시 사유를 반영해 AI가 다시 짭니다. 모든 변경은 버전으로 남아 언제든 되돌립니다.

### 2-2. 세 가지 고통을 끝내는 ChronOS 핵심 흐름
- **고통 ① 해결 (수십 가지 조건 검토 → 4겹 하네스 & 즉시 미리 보기)**: 조건 창에서 타워크레인 1대→2대처럼 값 하나만 바꾸면 간트차트에 점선으로 즉시 미리 보기(1초 미만).
- **고통 ② 해결 (밤샘 반복 → 대화 한 줄로 지연 → 만회안 → 비교판 → 승인)**: *"골조가 비 때문에 3일 늦어졌어"* 한 줄이면 영향 분석 → 만회안 A/B 자동 생성 → 비교판(같은 차트·다중 안 요약표) 비교 → 승인·버전 저장.
- **고통 ③ 해결 (공종별 검토·자료 취합 → 5축 자료함 · 근거 자동 첨부 · 모바일 현장 앱)**:
  - 시방서 PDF·현장 사진·엑셀 공정표를 대화에 붙이면 5축(`종류·공종·현장·시기·출처`) 자동 분류·Qdrant 뜻+낱말 검색.
  - 엑셀 공정표는 에이전트가 먼저 물어보고 빈 칸만 질문지/추정으로 채워 일정 초안으로 가져오기.
  - 기상청 공공데이터(ASOS·단기예보) + Liner Search/MCP(법령·기업) 근거를 조건 출처로 자동 연결.
  - **사무실에서는 OS 멀티태스킹, 현장에서는 스마트폰 전용 `MobileShell`(≤768px 자동 전환)**으로 사진 첨부·지연 보고·이동 중 즉시 승인.

## 4. 확장성과 임팩트 (20%)

### 4-1. 정량적 시간 절감
- **만회 계획 수립**: 반나절~밤샘 → **대화 한 줄 + 코드 탐색 1초대 + 비교판 즉시 비교**
- **조건 변경 시뮬레이션**: 수작업 재작성 → **값 변경 즉시 점선 미리 보기(1초 미만)**
- **공종별 자료·근거 확인**: 폴더·메일 수색 → **5축 자료함 뜻+낱말 검색 + 출처 자동 연결**

### 4-2. 분야·조직·디바이스 확장
- **분야 확장 (이미 증명됨)**: 분야 팩(YAML) 하나만 바꾸면 동일 엔진으로 다른 산업에 즉시 적용됩니다. 시연에 **건설(5층 사무동 신축, 59개 액티비티)**과 **생산(가상 부품 공장 브래킷 BR-200, 30개 액티비티·설비 자원별 간트)** 두 분야를 모두 구현했습니다. 다음 단계는 R&D·사업화입니다.
- **베테랑 노하우 축적**: 「내 규칙」이 쌓일수록 개인과 조직의 기준이 하네스로 코드화됩니다.
- **사무실 + 현장 연결**: PC OS 멀티태스킹 + 스마트폰 전용 앱(`MobileShell`)으로 현장과 본사가 하나의 일정·승인·자료함 위에서 움직입니다.
