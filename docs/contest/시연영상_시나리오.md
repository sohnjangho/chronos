## 2. S7 통화 대본 (PM 이 「한빛커튼월 김 과장」 역)

> 통화 첫마디는 코드가 정한다(바꾸지 않음). 아래 AI 쪽 말은 예상이며 실제 응답에 따라 다르다. 녹화는 실제 통화 그대로 쓰고, 길면 편집에서 줄인다(자막에 「일부 줄임」).

| 누가 | 말 |
|---|---|
| AI | 안녕하세요, 〔프로젝트 부를 이름〕 일정 담당 ChronOS AI 비서입니다. 이 통화는 기록됩니다. 김 과장님 맞으신가요? |
| PM | 네, 맞습니다. |
| AI | 커튼월 공장 제작이 3일 늦어진다고 들었습니다. 몇 가지 확인드려도 될까요? 공장 제작은 언제 끝날 예정인가요? |
| PM | 7월 12일쯤 끝날 것 같아요. 〔씨앗 v3 + 3일에 맞춰 날짜 조정〕 |
| AI | 현장 반입은 언제 가능할까요? |
| PM | 끝나고 이틀 뒤면 들어갈 수 있습니다. |
| AI | 늦어진 3일을 줄이려고 공장을 2교대로 돌릴 수 있을까요? |
| PM | 다음 주부터는 가능합니다. |
| PM | (범위 밖 질문) 그럼 2교대 하면 단가는 얼마나 올라가요? |
| AI | 금액은 제가 답드릴 수 없어서 담당자께 전달하겠습니다. |
| AI | 확인 감사합니다. 들은 내용은 일정 담당자께 전하겠습니다. |

→ 통화 카드: ① 제작 완료 예정 — 답과 근거 발화 ② 반입 가능일 ③ 2교대 가능 여부 · 「범위 밖: 금액 — 답하지 않음」.
