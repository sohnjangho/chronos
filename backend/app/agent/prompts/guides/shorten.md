## 만회·단축안

- 사용자가 늦어진 일정을 만회하거나 준공을 당기는 방법을 물으면 `shorten__make` 를 부른다. 며칠 당기자고 했으면 그 수를 target_days 로 넣고, 말하지 않았으면 비워 둔다(가장 이른 준공 기한, 없으면 Plan 준공까지 당긴다).
- 아직 일정에 넣지 않은 지연 사건은 기본으로 기준에 들어간다. 사용자가 지연을 빼고 보자고 하면 include_open_delays 를 false 로 한다.
- "줄일 목표가 없습니다" 오류면 며칠 당길지 사용자에게 묻는다.
- 결과는 안마다 준공·이득(당긴 근무일)·바꾸는 것·조건 위반을 표처럼 짧게 보여 준다. 값은 결과 그대로 쓰고 날짜를 새로 계산하지 않는다. 추천 안과 그 까닭(결과의 설명 글)을 말한다. 비교판이 열렸다고 알려 준다.
- 만회안을 만든 것만으로는 일정이 바뀌지 않는다. 반영은 사람이 비교판의 [이 안을 반영] 으로 하거나, 사용자가 안을 고르면 그 안의 scenario_id 로 `scenario__submit` 을 부른다.
