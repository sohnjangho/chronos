## 목표
- 설정 → 화면에 「배경」 칸: 기본(지금 그라데이션) + 위 8종 + 「내 사진」.
- 그림마다 밝은 판·어두운 판(둘 중 하나만 있으면 그 하나를 둘 다에 씀). 밝게/어둡게 테마를 바꾸면 저절로 따라감.
- 내 사진: JPG·PNG·WebP, 10MB 까지, 계정별로 서버에 저장 → 다른 기기에서도 같음.
- 배치 방식 5가지: 채우기(기본, 넘치는 곳 자름)·맞추기(전체 보임, 남는 곳 배경색)·늘이기·바둑판·가운데. 바꾸면 미리보기에 바로 보임.
- 고른 배경·배치 방식은 계정별로 기억하고 기기끼리 맞춤.
- 데스크톱·태블릿·휴대폰 모두. 로그인 화면은 그대로(영상).

## 하지 않음
- 컨트롤러가 처음 그린 시안 10개는 쓰지 않음(PM 시안으로 대체).
- 그림 편집(자르기 틀 직접 끌기, 밝기 조절)은 없음.
- 다른 계정과 사진 공유 없음.

## 방식(고른 것: C — 코드로 그린 8종 + 그림 파일 자리)
- 8종은 `frontend/src/assets/wallpapers/<id>-light.svg`, `<id>-dark.svg` 벡터 파일(16:9 기준, 다른 비율은 가운데 기준 채우기). 무거운 필터(큰 흐림·노이즈)는 피하거나 아주 가볍게.
- 같은 폴더에 `<id>-light|dark.(jpg|png|webp)` 를 넣으면 그 그림이 SVG 보다 먼저 쓰임(아이콘과 같은 자동 탐지) — 나중에 PM 원본으로 바꿀 자리.
- 내 사진: 서버 표 하나(사용자당 한 장, 바이트·형식·크기), 업로드 때 매직 바이트로 형식 확인·10MB 상한·가로세로 상한, 응답은 로그인한 본인에게만. 새로 올리면 덮어씀. 지우기 가능.
- 고른 값(배경 id·배치 방식)은 계정 설정으로 저장(기존 개인 설정 저장 길을 씀).
