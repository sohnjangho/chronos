# 정보 API 범용 연결 설계 (2026-11-23)

상태: PM 승인 대기 · 방식은 PM 결정(B안 범용 연결, 11-23)

## 왜
에이전트가 일정 판단에 쓸 공공데이터를 기상청 하나가 아니라 여러 개 붙여 쓰게 한다. 종류마다 코드를 새로 짜지 않고, 관리자가 설정에서 주소·키·설명을 넣으면 에이전트가 바로 쓴다.

## 목표 / 하지 않는 것
- 목표: 관리자가 연결을 여러 개 추가·시험·삭제. 에이전트가 연결 목록을 보고 필요한 것을 골라 호출. 결과는 근거로 남고 답에 출처가 붙는다.
- 하지 않는 것: POST 등 쓰기 호출, OAuth, 응답을 코드가 통계 내기(기상청 전용 도구만 한다), 사용자별 연결(회사 전체 공유).
- 실패로 보는 것: 키가 모델·기록·화면에 새는 것, 에이전트가 연결에 없는 주소를 부르는 것.

## 접근
- A. 종류별 전용 도구 — 정확하지만 종류마다 반나절. (기상청은 이 방식으로 이미 있음, 그대로 둔다)
- **B. 범용 연결 — PM 선택.** 에이전트가 응답을 직접 읽으므로 숫자를 잘못 옮길 수 있다 → 근거 카드에 응답 원문 일부를 보여 사람이 확인할 수 있게 한다.

## 자료
`info_connections` 에 칸을 더한다(기존 줄은 그대로, preset `kma`):
- `preset`: `kma` | `generic`
- `description`(500자): 이 API 가 무엇을 주는지 — 에이전트가 읽고 고른다.
- `usage`(4,000자): 쓰는 법 메모 — 경로·필수 파라미터·예시. 에이전트가 읽고 호출을 짠다.
- `key_in`: `query` | `header`, `key_name`: 기본 `serviceKey`(헤더면 예: `Authorization`)
- `test_path`: 연결 시험에 쓸 경로+질의(선택)

## 에이전트 도구 (판단은 에이전트, 호출은 코드)
- `info.list` → 연결마다 `{id, name, kind, description, usage, status}`. 키는 없음.
- `info.call {connection_id, path, params}` → 코드가 `base_url + path` 를 GET, 키를 붙여 호출하고 응답을 돌려준다.
  - 응답: JSON 은 그대로, XML 은 JSON 꼴로 바꿔, 모델에게는 앞 3,500자(잘리면 「뒤는 생략 — 범위를 좁혀 다시 부르세요」).
  - 근거로 기록(mode `info`, 출처 = 연결 이름, 주소는 키를 뺀 것, 원문 앞부분 보관) → `evidence_id` 와 근거 카드.
  - 한 요청에 4번까지(실패 포함).
- 기상청 전용 `info.weather` 는 그대로(통계는 코드가 낸다).

## 안전
- GET 만. `path` 는 상대 경로만(`://`·`//`·`..`·`@` 거절) — 연결의 주소 밖으로 못 나간다. 리다이렉트는 따라가지 않는다.
- 주소는 저장할 때와 부를 때 모두 검사: http(s) 만, localhost·사설/링크로컬 IP 거절.
- 키: 암호화 저장·끝 4자리만 표시(기존과 같음). 모델에게 가는 응답·오류·근거·trace·로그에서 키 값(인코딩·디코딩 꼴 모두)을 지운다. `params` 에 `key_name` 과 같은 이름이 오면 거절.
- 시간 15초, 본문 300KB 까지만 읽음.

## 설정 화면 (기존 「정보 API 연결」 구역을 넓힘)
```
정보 API 연결                                  [+ 추가]
┌ 기상청 날씨 · 기상청(전용) · ● 정상 · 키 …a1B2 ─ [연결 테스트][고치기][지우기]
┌ 공휴일 · 범용 · ● 정상 · apis.data.go.kr/B090041/… · 키 …9xQz ─ [연결 테스트][고치기][지우기]
└  설명: 공휴일·대체공휴일(연·월별)

[+ 추가] → 종류 ( 기상청(전용) | 범용 )
  범용: [빠른 채움 ▾ 특일 정보 · 기상특보 · 대기오염 · …]
        이름 / 주소 / 키 / 키 넣는 곳(질의·헤더)·이름 / 설명 / 쓰는 법 / 시험 경로
```
- 「빠른 채움」: 추천 API 의 주소·키 이름·설명·쓰는 법·시험 경로를 채워 준다(키만 넣으면 됨). **공식 문서로 확인한 것만** 넣는다.
- [연결 테스트]: `test_path` 를 한 번 불러 HTTP 상태·걸린 시간·응답 앞 300자(키 지움)를 보인다. 공공데이터포털 오류 봉투(등록 안 됨 등)는 한국어로 풀어 준다.
- 관리자만.
